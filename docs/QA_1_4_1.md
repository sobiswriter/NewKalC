# KalC 1.4.1 quality pass

Reported device: Realme 8 5G, Android 13.

## Fixed
- Editorial photos used independent width/height scaling. They now use centered aspect-preserving crops and can open uncropped in the shared full-screen viewer. Ingredient thumbnails and saved history photos also open full-screen.
- The recipe detail page silently disabled cooking when quantities were unknown or ingredients were missing. Start cooking now opens a preparation checklist, with explicit quantity/state and equipment confirmations. Food avoidances remain blocking.
- Ingredients have separated rows; method steps have numbered cards and readable paragraph spacing.
- Plant-milk normalization hid almond/soy ingredients from their avoidance checks. Normalization is now limited to dairy/vegan matching, and whole-word matching prevents eggplant/coconut false positives.
- Cached recipe selection cancels pending responses. History refreshes ignore stale pages. Starting a new session cancels the previous reminder. More-ideas batches deduplicate recipe titles.
- Image callbacks retain the scan destination selected when the image was requested.

## Verification
The automated cooking regression now starts from a saved recipe and an empty pantry, verifies that Begin cooking is blocked, explicitly confirms the ingredient, and completes cooking. Image-viewer opening and closing is exercised in the native flow. Unit tests cover the plant-milk/eggplant cases. Existing scan/profile/provider/food guards remain enabled.

No claim of universal flawlessness: physical Realme camera/gallery providers and actual recipe execution still require hands-on checks. APK 1.4.1 uses the existing signing certificate and updates without uninstalling.

Final verification: 35 Android unit tests, 10 backend tests and six native cooking/meal/profile flows passed. Full release lint passed. The signed version 1.4.1 (code 6) installed over the existing app and cold-started successfully. Native regression coverage now includes opening an illustration full-screen and starting a saved recipe from an empty pantry through explicit ingredient confirmation. A physical Realme/Android 13 test was not performed; the available emulator runs API 36.
